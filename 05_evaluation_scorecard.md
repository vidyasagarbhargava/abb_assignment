# Evaluation Scorecard

| Area | G12 | G13 |
|---|---:|---:|
| Architecture and design | 25% | 15% |
| Python backend engineering | 15% | 20% |
| MLOps implementation | 15% | 20% |
| Angular implementation | 10% | 15% |
| TDD and code quality | 15% | 20% |
| Packaging, CI and operability | 10% | 10% |
| Technical leadership | 10% | 0% |

## Evaluate
- Architecture, domain model, APIs and extensibility
- Python structure, typing, validation, persistence and errors
- Registry, versioning, lifecycle, deployment, monitoring and rollback
- Angular components, services, RxJS, states and tests
- Unit, integration, UI and error-path testing
- Docker, CI, health checks and documentation
- For G12: trade-offs, scaling, roadmap, risks and leadership artifacts

## Red Flags
- Hard-coded workflows
- No persistence
- No tests
- No lifecycle validation
- Secrets in Git
- No error handling
- Repository cannot run
- Complexity without rationale
- Missing role-level deliverables

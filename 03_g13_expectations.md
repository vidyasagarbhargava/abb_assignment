# G13 – Senior Software Engineer Expectations

The submission should demonstrate strong independent engineering and a complete feature across Python, MLOps, Angular, testing and packaging.

## Mandatory Scope
- Working Python APIs
- Working Angular UI
- Model registry
- Deployment workflow
- Monitoring dashboard
- Persistence
- Unit and integration tests
- Basic Angular tests
- Docker packaging
- README and architecture diagram

## Engineering Expectations
- Clean code and reasonable boundaries
- Typed contracts and validation
- Consistent API errors
- Angular loading and error handling
- Reusable services and appropriate RxJS usage
- Database migrations or documented schema setup
- Environment-based configuration
- Deterministic fixtures and tests

## Questions to Address
1. Why was the framework selected?
2. How are domain entities represented?
3. How are invalid lifecycle transitions prevented?
4. How are API errors standardized?
5. How does Angular handle loading and failure?
6. How are tests isolated from live systems?
7. How is configuration managed?
8. How would the design extend to a real serving platform?
